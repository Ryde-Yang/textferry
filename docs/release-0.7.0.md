# 0.7.0：内容保全、恢复与首次使用

带图文字 PDF 现在保留本地图示；EPUB 的正文、脚注和代码分别处理，原生提取中断后可在本机继续。安装器通过离线自检后才报告可用。新增范围选择、追加格式和升级整理入口，让常见后续请求复用已有文字。

## 发布审核问题的处理

| 问题 | 修复行为 |
|---|---|
| 文字 PDF 丢失图片 | 保存可提取图片和矢量图示区域，保留源页与位置记录；Markdown / Word 使用同一资源 |
| EPUB 正文重复进入脚注 | 区分注释节点内部内容与外部尾文，各自保留一次 |
| EPUB 恢复误要求 OCR | 按来源格式恢复，只处理待提取章节，保留已完成结果与工作稿 |
| 修改配图后核查仍有效 | 工作稿及 EPUB 对照来源引用的图片纳入哈希；缺失或改变后核查失效 |
| 无 uv 安装状态不清 | Python 虚拟环境与 pip 路径可完成安装；依赖失败返回未就绪，安装完成执行离线样本自检 |
| EPUB 代码中的脚注语法被改写 | 在结构层为真实注释编号，保留代码原文；整理导出的注释检查也区分代码 |
| 内嵌 SVG 无法进入 Word | 保留安全 SVG 原件，生成本地 PNG，供 Markdown / Word 一致引用 |
| 注释返回链接无目标 | 保留正文引用锚点，返回链接对应实际目标 |

这些复现样本已加入正式回归。资源检查覆盖正文和脚注中的图片，也区分代码示例中的字面图片语法。

## 常见后续请求

- `convert --pages 2-10,13` 选择 PDF 原文件物理页，保留完整来源及原编号映射。
- `convert --chapters 2-5` 选择 EPUB 内容单元；先按章名核对目录。只提取所选范围，保留其中实际包含的正文与注释。
- `change-output --format word` 在原任务追加 Word；基础稿的显式格式追加可使用当前修订。公式方式可选 `--equations native|compatible`，写入任务供后续沿用。
- `upgrade-review` 从底稿建立整理工作区，保留原机器文字，不重新 OCR。直接修订先对应回来源，整理稿重导出仍受文件保护约束。
- `doctor` 验证本机环境与离线样本，不调用 OCR。安装更新保存旧文件副本，其他本地文件与独立凭证保留。

所选范围中不连续的源页 / 章节需分开接续。内部工作单元从 1 编号，原始编号由来源映射保存并用于可读显示。

## 引导与说明

依据 writing-for-agents 的信息层级、条件指针和完成标准打磨指令：主入口 68 行，分支细节按环境、EPUB、Word、核查和共享分别读取；首页从首次使用出发。

用户先了解并选择基础转换或 AI 整理校正，再选 Markdown / Word，推荐 Markdown；已有选择直接沿用。内部参数由 Agent 处理。费用与共享库情况按需说明，令牌在需要 OCR 时配置；具体疑难用普通中文放在《整理说明》中。

程序提供提取、等待识别、取回结果与 Word 导出的阶段事件。长材料以约定范围为边界，仍不能确定的内容保留位置与疑难，不把单个字扩展成无边界校核。

## 验证与仍有限制

验证结果见 [验证记录](verification.md)。本轮使用自制 PDF / EPUB，覆盖安装目录独立运行、基础 / 整理与 Markdown / Word、范围和后续格式操作。安装依赖使用网络；材料验证不调用真实 OCR。

尚无真人小白可用性试验，也未完成 Windows / Linux 的同等验证。纯扫描、受保护和交互式 EPUB 不属于完整支持范围；固定版式不复刻版面。复杂表格与章节锚点在不同 Markdown 阅读器中可能表现不同；Word 与所选阅读器的实际显示需按任务检查。

共享仍限纯文字 PDF 成品，默认公共索引尚未启用。网站、跨扫描底本匹配和独立专家校审属于后续范围。
