# TextFerry 0.9 系列发布审核

2026-10-28，当前 Agent 在更名后复核源码、Skill 指令、安装与更新、任务恢复、OCR 回执、来源保护、PDF / EPUB、Markdown / Word、核查记录、成品交付、缓存清理和共享边界。审核结合人工阅读、可复现失败和自动回归；不将测试通过当作所有材料均能准确整理。

## 本轮修复

| 问题 | 影响与修复 | 验证 |
| --- | --- | --- |
| 更新沿受管理文件的符号链接写入 | 可能修改安装目录外的文件；所有受管理路径在备份、写入前统一检查 | 文件、父目录、安装记录三种链接均先失败复现，再验证拒绝更新且外部内容保持原值 |
| 两种百度环境令牌的优先级不一致 | 诊断报告与实际请求可能使用不同令牌；引擎统一调用凭证解析器，显式传入的令牌仍优先 | 同时设置两种自制令牌，验证请求与安全诊断一致 |
| EPUB 章节缺少 body 时无有效报错 | 不完整章节会造成空白错误；检查阶段明确指出缺少正文及章节文件名 | 自制异常 EPUB 先复现，再验证有意义的错误 |
| 一项混合 PDF 测试依赖本机令牌 | 在没有用户配置的环境失败；测试显式使用自制凭证，整个套件隔离用户凭证 | 更名后的完整回归通过 |

## 命名与公开范围

公开仓库、Skill、Python 包、命令、环境变量、安装位置和配置 / 缓存目录统一为 `textferry` / `TEXTFERRY_*`；品牌显示为 TextFerry。发行源码不包含本机凭证、真实书籍、转换全文、私人对话、虚拟环境、缓存和历史试验包。示例内容为自制片段或明确标识的公版演示。

主流程仍先解释基础转换与 AI 整理校正的区别，再确认格式、长材料范围，以及整理稿的来源页码 / 章节标记。已知选择直接沿用；组件和缓存由 Agent 处理。重新按 writing-for-agents 检查名称、条件指针、步骤顺序、完成标准和单一规则来源。

## 发布边界

- 首次公开作为 **0.9 系列预发布版**，便于早期使用者反馈。当前未发现需要阻断这一范围公开的已知问题。
- 实际跨宿主对话验证以 Codex、Pi / Flash 为主；其他 Agent 的自动发现、权限和对话体验未逐一验收。
- 本轮更名没有重复付费 OCR 或重新校对整本真实书籍；已完成的真实材料和 Pi 记录见此前验证文档。页码主动询问已有明确指令，但尚未补做新的完整真实模型对话验证。
- 多栏、竖排、异体字、复杂公式、残缺页面仍需按实际材料对照；AI 整理不等于人工学术定本。
- 带保护、纯扫描及交互式 EPUB 不在完整支持范围内；部分固定版式只能保留内容结构。具体边界见 Skill 对应参考。
- Word 复杂公式可能使用图片；中文显示也取决于预览环境字体。
- 共享索引暂为空；现阶段只支持符合权利要求的纯文字 PDF 贡献，且公开前需对具体版本单独同意。

验证结果见 [验证记录](verification.md)。GitHub 自动回归只运行自制材料和模拟服务，不使用维护者或贡献者密钥。
