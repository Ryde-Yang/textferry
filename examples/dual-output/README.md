# 双产物示例：古籍竖排版式

一页自制测试材料，包含经文、注、疏三列；用于说明交付形式，不是正式古籍整理成果。

- [机器底稿](machine.md)：按页保留机器识别文字。
- [手洗稿](handwashed.md)：实际查看页图后整理经、注、疏，隐藏页码。
- [显示页码的同稿](handwashed-with-pages.md)：相同正文，显示 PDF 页标记。

`content.md` 是用于共享复用的逐页文字，`manifest.json` 记录来源指纹、质量、范围和文本校验值。示例不包含原 PDF、私人映射或核查自由文字。

测试说明：实际百度 OCR 后回看完整源页，确认右至左三列；合并疏列断行，经文加粗，注疏独立。只验证这一页，未做版本校勘或独立专家复核。

现代测试文字与版式由本项目自制；贡献许可 CC0-1.0 仅涵盖可授权部分，经文短句为古典原文。示例生成程序为 `skills/textferry/scripts/make_samples.py`。
