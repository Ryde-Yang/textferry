# 材料整理示例

以下片段说明表现形式，不能代替对实际底本的判断；标签、断句、注家名必须来自所处理材料。

## 经、注、疏

```markdown
**经文原句。**

【注】底本所载古注。

【疏】底本针对这段经注的解释。
```

经文与解释就近；若底本逐句展开，不把整章注疏集中压到章末。已有章指、章旨按原文保留，不自行撰写。大字与小字被 OCR 连在一起时，要回看版面恢复归属，不能只根据语义猜分。

## 正义、集注与校勘

正义可能在一段释文中串联多家解释，应保留原本完整组织，不因为出现“某氏曰”就拆成新的层级。集注可能逐节附注并另附章末总论，应保留这些位置和内容。它们不需要套用经注疏的同一种模板。

现代整理者校勘记按实际锚点归位，并与连续释文区分；书页底部的小字并不一定都是作者脚注。无法确认时保留并待核，不补造锚点。

## 论文的两套引用

```markdown
作者的正文。[^1] 对另一文献的引用。[^ref-1]

## 注释

[^1]: 作者在本页的解释性原注。

## 参考文献

[^ref-1]: 对应原书书目条目的完整文字。
```

两套编号独立。不能把同一个数字对应的原注和参考书目合为一条。源页没有正文标记时，不为配对成功而添加标记。

## 现代研究图书与跨页

作者正文、论证和例证完整保留；长引文可用引文块，随后作者分析退出引文块。跨页同句在 `layout.json` 中标 `join`，另段或另章用 `separate`，均以相邻来源页为准。

先检查跨页是否仍在同一引文、列表、表格或公式中，再恢复结构。对照目录、章首和章尾判断边界，不按 OCR 自动编号创建章节。
